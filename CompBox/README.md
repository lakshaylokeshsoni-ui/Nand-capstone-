# CompBox — Hack computer lab (Lakshay, K = 83)

Open `index.html` in a browser (no server or install needed).

- Simulator: runs Box (K=83), Rect, Max, Add, Pong on a Hack CPU emulator; Box designer for any K.
- Assembler: two-pass, line-numbered errors + duplicate-label warnings, listing/binary/symbols, compare with official output.
- Hardware: HDL files from the K=83 submission, memory-map and instruction decoders.
- Tests: 12 live checks plus the K=83 screenshots.
- Projects: submission details and downloads.

Files: `js/hack.js` (engine), `js/app.js` (UI), `js/data.js` + `js/pong-data.js` (bundled sources).
